# Trilok Krishnan – Insurance Advisor Web App (Premium Preview)

> **PREVIEW VERSION** – This is a high-end visual/product preview for presentation to the insurance advisor before actual development. Not the official corporate website of Tata AIG General Insurance Company Limited.

## Concept

Premium mobile-first **Insurance Advisor Web App** designed as:

- Professional insurance application
- Modern fintech platform
- Premium client portal
- Trusted advisor's digital office
- Enterprise-level web application

Goal: Client can **understand insurance options, check process, understand documents and services, and then directly contact advisor on WhatsApp**. Reduces repetitive explanations.

Final action: **Talk to Advisor on WhatsApp**

## Design Standard

- Premium ₹1,00,000+ project feel
- Clean, bold, trustworthy, sophisticated, minimal
- White + deep navy #0E1E3A + Tata AIG-inspired red #E31E24 + neutral gray
- Red only for CTA
- Glassmorphism, premium cards, micro-interactions, generous spacing, excellent typography (Inter + Sora)
- Mobile-first, PWA feel

## Features Implemented

- **Hero**: "Insurance Made Simple. Guidance You Can Trust." + advisor identity TRILOK KRISHNAN
- **Quick Service Dashboard**: 12 app-style cards (Motor, Car, Bike, Health, Travel, Commercial, Personal Accident, Renewal, Claim Assistance, Policy Assistance, Document Guidance, Talk to Advisor)
- **Search**: App-style search bar for insurance information
- **Motor Section**: Car, Bike, Commercial Vehicle with coverage concepts, documents, disclaimer
- **Health Section**: Family protection, hospitalization, cashless, documents
- **Travel Section**: Domestic, International, medical assistance
- **Commercial Section**: Business-oriented insurance guidance
- **Claim Assistance**: 5-step visual process (Inform Advisor → Share Details → Document Guidance → Claim Process Assistance → Track/Follow Up) – dark premium section
- **Document Checklist**: Interactive category switcher (New, Renewal, Vehicle, Health, Travel, Claim)
- **How It Works**: 4-step timeline
- **Why Advisor**: 6 premium cards (Personal guidance, Easy information access, Document guidance, Renewal assistance, Claim assistance, Direct WhatsApp)
- **About Advisor**: Professional profile with placeholder avatar TK
- **WhatsApp Conversion System**: Floating button + modal with enquiry selection (Car, Health, Bike, Travel, Renewal, Claim, Other) → placeholder wa.me link
- **FAQ**: Premium accordion, schema-ready
- **Local SEO Architecture**: Future-ready structure for Bihar cities (Muzaffarpur, Patna, Gaya, etc.) and routes like /insurance-advisor-bihar, /car-insurance-bihar etc. No spam pages – placeholder architecture shown
- **SEO Foundation**: semantic HTML, heading hierarchy, Open Graph, metadataBase, robots.txt, sitemap.xml, manifest, Organization/Person schema, accessibility, Core Web Vitals optimized
- **PWA / Web App Feel**: sticky bottom mobile nav (Home, Services, Claims, Documents, Contact), app-style transitions
- **Desktop**: Premium navbar with mega-menu for insurance services, right CTA
- **Footer**: Disclaimer – Not official Tata AIG corporate website

## Tech Stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons
- SEO: sitemap.ts, robots.ts, manifest.ts, JSON-LD

## Privacy & Compliance

- No personal phone, address, Aadhaar/PAN, email, private documents exposed
- Uses placeholder WhatsApp link (wa.me/?text=)
- Generic/sample information only
- Disclaimer: "Coverage and terms depend on selected policy..."
- No fake testimonials, ratings, awards, client counts, claim settlement stats
